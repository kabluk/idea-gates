# inbox

Drop anything here, one file per item, any format: a sentence, a link, a
pasted article, a book title with "read this", a voice-note transcript.
File names do not matter; a date prefix helps.

The librarian empties the inbox (`inbox` mode): each item becomes a library
note, a world fact, an idea card seed, a playbook proposal, or is deleted
with a one-line reason in its log. Nothing stays here longer than a week.
