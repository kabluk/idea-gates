# world

Facts about markets, regulations, platforms and prices. Facts go stale, so
each one carries where it came from and when to re-check it:

```
---
source: <URL or brain note>
checked: <YYYY-MM-DD>
expires: <YYYY-MM-DD — when this must be re-verified>
---
# <the fact in one line>

<detail, numbers with [src: ...] when they come from a JSON in ideas/>
```

Pick `expires` by how fast it changes: prices and search volumes 3 months,
platform rules 6 months, laws 12 months. The librarian's garden pass
re-verifies expired facts or moves them to `world/archive/`.
