# library — the shared knowledge the roles are built on

Notes on the books and essays the agents' playbooks cite, written in our own
words: the ideas that change what an agent does, how idea-gates applies them,
and where they stop working. They are not summaries of the whole work and
quote nothing at length — read the original for the argument.

Each playbook rule points to a note here, so a disagreement about a rule can
be settled against its source. Project-specific notes (books the founder
adds, industry knowledge) live in the project's `brain/library/`, written by
the librarian; a note that proves useful across projects can be proposed
back here.

|---|---|---|

| `walling-start-small.md` | Rob Walling, *Start Small, Stay Small* (2010) | scout, judge |
| `kahl-embedded-entrepreneur.md` | Arvid Kahl, *The Embedded Entrepreneur* (2021) | scout |
| `kim-mauborgne-blue-ocean.md` | W. Chan Kim, Renée Mauborgne, *Blue Ocean Strategy* (2005) | scout, ocean analyst |
| `tetlock-superforecasting.md` | Philip Tetlock, Dan Gardner, *Superforecasting* (2015) | scout, auditor, judge |

Note format: what the work is, the ideas we use (each with "so the agent
does…"), the limits, and which playbook rules cite it.
