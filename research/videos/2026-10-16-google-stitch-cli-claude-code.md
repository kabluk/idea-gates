# Claude Code + Google Stitch: дизайн сайта силами агента

- Источник: https://www.youtube.com/watch?v=au2TI8sdq8E (AI LABS, 2026-10-13, 13:47)
- Разобрано: 2026-10-16 · **сигнал 6/10**
- Профиль основателя: `docs/FOUNDER.md` не найден, оценки для соло-исполнителя без портфолио

## 0. Вердикт

- **Что это даёт:** Claude Code теперь сам управляет Google Stitch: делает несколько вариантов дизайна, отбраковывает слабые и собирает из лучшего живой адаптивный сайт со scroll-анимациями. Лендинг уровня «дизайнер + верстальщик» — за вечер одному.
- **Сигнал 6/10:** свежий рабочий инструмент (CLI вышел 2026-10-01) плюс проверяемая ниша на биржах.
- **Смотреть самому?** Нет, инструкция ниже полнее. Если хочется увидеть результат глазами — финальный сайт со scroll-анимациями на `[11:27]–[12:01]`.

## 1. Что это открывает

- **Дизайн без дизайнера:** Stitch (Google, модели Gemini) делает макеты заметно аккуратнее, чем сам Claude, а теперь вызывается из терминала — агент может перебрать 5–10 вариантов без вашего участия.
- **Редизайн чужой страницы за минуты:** `stitch capture` забирает существующую страницу в Stitch, дальше «перерисуй это». Готовый продукт для гига «редизайн».
- **Scroll-сторителлинг:** с отдельным скиллом Claude делает сайты, которые «рассказывают историю» при прокрутке — то, что на биржах продают как «премиум-лендинг с WOW-анимациями».
- **Автопроверка адаптива:** скилл-ревьюер снимает скриншоты на 3 ширинах и чинит то, что сломалось на телефоне. Отдельно продаётся как «правки мобильной версии».

## 2. Инструкция

### Что нужно (проверено 2026-10-16)

- Node.js 20+, Claude Code, Google-аккаунт.
- Stitch бесплатный (Google Labs), лимит — дневные кредиты (с апреля 2026; точные цифры у источников расходятся, смотрите баланс в настройках Stitch). Платного тарифа нет.
- CLI: пакет [`@google/stitch`](https://www.npmjs.com/package/@google/stitch), версия 0.11.1 от 2026-10-08. Молодой — флаги могут меняться.

### Шаги

**1. Установить и войти** (5 мин)
```bash
npm install -g @google/stitch
stitch login          # откроется браузер, вход через Google
stitch status         # проверить, что вошли
```

**2. Подключить скилл Stitch к Claude Code** (2 мин)
```bash
stitch agent-skills add                       # пишет в .agents/skills — Claude Code туда не смотрит
mkdir -p .claude/skills && cp -r .agents/skills/* .claude/skills/
```
Без копирования в `.claude/skills` Claude не узнает, что Stitch вообще есть `[03:17]`.

**3. Добавить скилл для scroll-анимаций** (2 мин)
```bash
mkdir -p .claude/skills/scrollytelling
curl -sL https://raw.githubusercontent.com/doodledood/claude-code-plugins/HEAD/claude-plugins/frontend-design/skills/scrollytelling/SKILL.md \
  -o .claude/skills/scrollytelling/SKILL.md
```

**4. Бриф** (15–20 мин) — промпт в Claude Code:
```
Я хочу сделать сайт: <одна фраза о сайте>. Проинтервьюируй меня: задавай вопросы
по одному, к каждому давай 3–4 варианта ответа, пока не поймёшь идею полностью —
историю, которую сайт рассказывает при прокрутке, настроение, цель, аудиторию.
Когда вопросов не останется, запиши всё в brief.md: краткое резюме, затем история
сайта по секциям в порядке прокрутки.
```
Все дальнейшие промпты в Stitch идут из этого файла — так дизайны не «гуляют» по стилю.

**5. Дизайн в Stitch** (30–60 мин, работает агент)
```
Используя скилл Stitch и brief.md как единственный источник, создай проект в Stitch
и сгенерируй 3–4 варианта дизайна для DESKTOP и MOBILE. Проверяй каждый вариант
против brief.md; если видишь проблему — генерируй исправленный. Остановись, когда
есть вариант без замечаний, и покажи ссылки на превью.
```
Ручной контроль: `stitch serve -p <project-id>` — локальный просмотр всех экранов.
Варианты вручную: `stitch generate variants --project <id> --screen <id> --count 3 --creative-range EXPLORE`.

**6. Сборка сайта** (20–40 мин)
```
Скачай выбранный дизайн из Stitch (HTML, картинки, шрифты) и собери из него сайт
в этом проекте. Пока без больших анимаций.
```

**7. Проверка адаптива** (15 мин) — создать свой скилл-ревьюер один раз:
```
Создай скилл design-review в .claude/skills: он открывает сайт в Playwright,
снимает скриншоты на 375, 768 и 1440 px, сравнивает с дизайном из Stitch и пишет
отчёт — проблемы от худших к мелким. Затем запусти его и исправь всё из отчёта.
```

**8. Scroll-анимации** (30–60 мин)
```
Используя скилл scrollytelling и brief.md, добавь анимации прокрутки так, чтобы
каждая секция продолжала историю. Каждая анимация должна работать на историю,
а не для красоты.
```

**9. Жёсткое ревью истории** (15 мин):
```
Создай скилл story-review: оценивает сайт как жюри Awwwards — течёт ли история,
служит ли ей каждая анимация, темп прокрутки, тексты — против brief.md. Отчёт по
каждой секции: работает / доработать, проблемы по серьёзности. Затем исправь всё.
```
Главное, что он ловит: перебор анимаций. Claude их ставит слишком много `[12:01]`.

### Где споткнётесь

- **`MISSING_CANVAS_CREDENTIALS`** — часть команд (проекты, экраны, дизайн-системы) требует API-ключ даже после `stitch login`. Решение: `export STITCH_API_KEY=...` (ключ в настройках Stitch). Это в «известных ограничениях» CLI.
- **Сайт ломается на телефоне,** если Stitch делал только DESKTOP. Всегда просите оба устройства и прогоняйте шаг 7 до анимаций.
- **Кредиты кончаются:** 8 итераций на страницу — заметная часть дневного лимита. Для клиентских заказов не делайте больше 3–4 вариантов на раунд.
- **Скилл не виден агенту** — проверить: `ls .claude/skills`.

### Результат

Адаптивный лендинг со scroll-сторителлингом. Оценка по шагам: **≈ 3–4 часа на первый, 2–3 часа на следующие** (пока не измерено — первое действие плана ниже как раз это проверяет).

## 4. Крупнее: продукт

Отдельного продукта видео не открывает: процесс копируется за вечер всеми, кто его посмотрел. Единственный кандидат — **открытый скилл design-review** (скриншоты на 3 ширинах + отчёт): прямых денег не даёт, но даёт репутацию в нише Claude Code-скиллов. Ворота 1–6 проходит, ворота 3 («деньги») — нет, поэтому это вложение в доверие, а не бизнес.

## 5. План

- **Сегодня (≤ 1 ч):** шаги 1–5 инструкции на лендинге-концепте для кофейни. Засечь время и расход кредитов — это главная неизвестная во всей экономике гигов выше.
- **На этой неделе:**
  1. Довести 3 концепта до конца (шаги 6–9). Готово: 3 ссылки на живые страницы и записанное время каждой.
  2. Сделать 2 «до/после» через `stitch capture`.
  3. Опубликовать гиги №1 и №2 на Kwork.
- **30 дней:** метрика — заказы и отзывы; бюджет — $0 и ~15 часов на портфолио. **Критерий остановки:** см. выше; плюс если реальное время на лендинг > 7 часов, гиг №1 нерентабелен по этим ценам — пересчитать.

## 6. Почему работает и сколько продлится

Рычаг — подешевевший дизайн: генерация макетов почти бесплатна, а Claude Code связывает генерацию, сборку и проверку в один конвейер. Ценность смещается от «умею рисовать» к «умею поставить задачу и проверить результат». Бриф и ревьюер — это и есть новая квалификация.

Окно на биржах: англоязычный Fiverr заполнится такими гигами за недели (56K зрителей за 3 дня). Русскоязычный Kwork отстаёт: 13 предложений по scroll-анимации сейчас — на месяцы, если зайти первым и набрать отзывы. Отзывы, а не процесс — это то, что нельзя скопировать.
