# Свой личный ИИ-агент на сервере + гиг на Kwork — за один вечер

Что будет к концу вечера:

1. У вас работает **Rakazo** — open-source личный ИИ-агент (аналог Grok Bot): чат в браузере и в телефоне, у агента свой компьютер с браузером, он сам выполняет задачи.
2. Есть короткое видео и скриншоты для портфолио.
3. Опубликован (или отправлен на модерацию) гиг на Kwork «Установлю личного ИИ-агента на ваш сервер».

**Время:** около 3 часов. **Деньги:** сервер (обычно 700–1500 ₽ / 7–15 € в месяц, смотрите цену у провайдера) + $5 на ИИ-модель.

Инструкция проверена по официальной документации Rakazo на 16 октября 2026. Проект быстро меняется: если что-то выглядит иначе, первоисточник — [docs/self-host.md](https://github.com/elie222/rakazo/blob/main/docs/self-host.md).

---

## Как пользоваться инструкцией

- Команды в серых блоках копируйте **целиком** и вставляйте в терминал сервера. Ничего в них не меняйте, кроме того, что написано `ВОТ_ТАК` большими буквами.
- После каждого шага есть строка **✅ Проверка** — что вы должны увидеть. Не увидели — не идите дальше, смотрите раздел «Если что-то пошло не так» в конце.
- В тексте ниже `203.0.113.10` — пример адреса сервера. Везде подставляйте **свой** адрес.

## Шаг 0. Что подготовить (10 минут)

- [ ] Банковская карта для оплаты сервера.
- [ ] Почта, к которой у вас есть доступ.
- [ ] Аккаунт на [OpenRouter](https://openrouter.ai) — это «магазин» ИИ-моделей с одной оплатой. Зарегистрируйтесь, в разделе **Credits** пополните на $5, в разделе **Keys** создайте ключ и сохраните его в заметки (начинается с `sk-or-`). Ключ показывается один раз.
- [ ] Телефон с App Store или Google Play — проверим мобильное приложение.
- [ ] Программа для записи экрана: на Windows — **Win+G**, на Mac — **Cmd+Shift+5**, или бесплатный [OBS](https://obsproject.com).

## Шаг 1. Арендовать сервер (15 минут)

Нужен сервер с такими параметрами — **не меньше**, иначе агенту не хватит памяти:

| Параметр | Значение |
|---|---|
| Процессор | 4 ядра (vCPU) |
| Память | **8 ГБ** |
| Диск | от 80 ГБ |
| Система | **Ubuntu 24.04** |

Почему 8 ГБ: Rakazo — это пять программ (база данных, сервер, фоновые задачи, сайт, управляющий компьютерами), плюс у каждого бота свой компьютер с браузером — по умолчанию до 2 ГБ.

Где взять:
- **Hetzner Cloud** — [hetzner.com/cloud](https://www.hetzner.com/cloud), дешёвые серверы в Европе, нужна зарубежная карта. Подойдёт тариф с 4 vCPU и 8 ГБ (на момент написания — CX33 или ARM-вариант CAX21; Rakazo работает на обоих).
- **Timeweb Cloud** — [timeweb.cloud](https://timeweb.cloud), если удобнее оплата российской картой. Выберите конфигурацию 4 ядра / 8 ГБ.

При создании сервера:
1. Система — **Ubuntu 24.04**.
2. Если предлагают **SSH-ключ** — лучше добавить (так безопаснее пароля). Как создать ключ: откройте на своём компьютере терминал (Windows — PowerShell, Mac — Terminal) и выполните:
   ```bash
   ssh-keygen -t ed25519
   ```
   На все вопросы нажимайте Enter. Потом покажите ключ:
   ```bash
   cat ~/.ssh/id_ed25519.pub
   ```
   Скопируйте строку целиком (начинается с `ssh-ed25519`) и вставьте в поле SSH-ключа у провайдера.
3. Если ключ не добавляли — провайдер пришлёт пароль root на почту.

✅ **Проверка:** в панели провайдера сервер в статусе «Работает», и вы видите его **IP-адрес** (вида `203.0.113.10`). Запишите его.

## Шаг 2. Подключиться к серверу (5 минут)

На своём компьютере в терминале:
```bash
ssh root@203.0.113.10
```
(подставьте свой IP). На вопрос `Are you sure you want to continue connecting` напишите `yes` и Enter. Если нужен пароль — вставьте пароль из письма (при вводе он не отображается, это нормально).

✅ **Проверка:** строка терминала стала вида `root@имя-сервера:~#`. Теперь всё, что вы вводите, выполняется на сервере.

Сразу обновите систему (2–5 минут):
```bash
apt update && apt upgrade -y
```
Если появится розовое окно с вопросом про перезапуск служб — нажмите Enter.

## Шаг 3. Поставить Docker и закрыть лишние порты (5 минут)

Docker — программа, которая запускает Rakazo в готовых «контейнерах». Официальный установщик:
```bash
curl -fsSL https://get.docker.com | sh
```
Проверьте версии:
```bash
docker --version && docker compose version
```

✅ **Проверка:** `Docker version 26` или выше (Rakazo требует не ниже 26) и строка `Docker Compose version v2...`.

Теперь брандмауэр — откроем только вход по SSH и веб (80, 443):
```bash
ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw --force enable
```

✅ **Проверка:** `Firewall is active and enabled on system startup`.

## Шаг 4. Адрес для сайта — без покупки домена (2 минуты)

Для HTTPS нужен домен. Чтобы не покупать его сегодня, используем бесплатный сервис [sslip.io](https://sslip.io): он превращает IP в адрес. Возьмите свой IP, замените точки на **дефисы** и допишите:

```
rakazo.203-0-113-10.sslip.io
```

Задайте адрес и свою почту как переменные — дальше команды подставят их сами (так меньше опечаток):
```bash
DOMAIN=rakazo.ВАШ-IP-ЧЕРЕЗ-ДЕФИСЫ.sslip.io
EMAIL=ВАША_ПОЧТА@example.com
echo "$DOMAIN  $EMAIL"
```

✅ **Проверка:**
```bash
getent hosts $DOMAIN
```
показывает ваш IP-адрес.

> Если вы переподключитесь к серверу, переменные пропадут — просто выполните две строки `DOMAIN=…` и `EMAIL=…` снова.

Свой домен можно подключить позже, когда будете показывать клиентам.

## Шаг 5. Скачать Rakazo и настроить (10 минут)

Создайте папку и скачайте официальный установщик в режиме «только подготовить»:
```bash
mkdir -p ~/rakazo && cd ~/rakazo
curl -fsSLO https://raw.githubusercontent.com/elie222/rakazo/main/infra/compose/install-images.sh
bash install-images.sh --prepare-only
```

✅ **Проверка:** в конце `Created .env with random secrets.` и `Rakazo files are ready.` Установщик сам придумал все пароли и секретные ключи — их трогать не нужно.

Теперь впишите в настройки ваш адрес и почту. Эта команда сама поправит нужные строки файла `.env`:
```bash
sed -i \
  -e "s|^BETTER_AUTH_URL=.*|BETTER_AUTH_URL=https://$DOMAIN|" \
  -e "s|^WEB_ORIGIN=.*|WEB_ORIGIN=https://$DOMAIN|" \
  -e "s|^API_URL=.*|API_URL=https://$DOMAIN|" \
  -e "s|^RAKAZO_HOST=.*|RAKAZO_HOST=$DOMAIN|" \
  -e "s|^SIGNUP_ALLOWLIST=.*|SIGNUP_ALLOWLIST=$EMAIL|" \
  .env
grep -E "^(BETTER_AUTH_URL|WEB_ORIGIN|API_URL|RAKAZO_HOST|SIGNUP_ALLOWLIST)=" .env
```

✅ **Проверка:** пять строк, в первых трёх `https://rakazo.…sslip.io`, в `RAKAZO_HOST` — адрес **без** `https://`, в `SIGNUP_ALLOWLIST` — ваша почта.

Зачем `SIGNUP_ALLOWLIST`: **первый зарегистрированный пользователь становится владельцем сервера**, а регистрация по умолчанию открыта всем. Список разрешённых почт не даст чужому человеку зарегистрироваться раньше вас и пользоваться вашим сервером.

## Шаг 6. Запустить Rakazo (10–15 минут, в основном ожидание)

```bash
bash install-images.sh
```
Установщик скачает образы (несколько гигабайт) и подождёт, пока всё запустится — до 5 минут после скачивания.

✅ **Проверка:** последняя строка `Rakazo is starting at http://127.0.0.1:5173`. И состояние сервисов:
```bash
docker compose --env-file .env -f docker-compose.images.yml ps
```
У `postgres`, `supervisor`, `api`, `worker`, `web` в колонке STATUS — `Up` (у некоторых ещё `(healthy)`).

Сайт пока доступен только изнутри сервера — это сделано специально. Наружу его выпустит Caddy на следующем шаге.

## Шаг 7. HTTPS через Caddy (10 минут)

Caddy — веб-сервер, который сам получает бесплатный HTTPS-сертификат. Установка по [официальной инструкции](https://caddyserver.com/docs/install#debian-ubuntu-raspbian):
```bash
apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | tee /etc/apt/sources.list.d/caddy-stable.list
chmod o+r /usr/share/keyrings/caddy-stable-archive-keyring.gpg /etc/apt/sources.list.d/caddy-stable.list
apt update && apt install -y caddy
```

Настройте его на ваш адрес (команда сама подставит `$DOMAIN`):
```bash
printf '%s {\n\treverse_proxy 127.0.0.1:5173\n}\n' "$DOMAIN" > /etc/caddy/Caddyfile
cat /etc/caddy/Caddyfile
systemctl reload caddy
```

✅ **Проверка:** подождите 30 секунд и выполните
```bash
curl -sI https://$DOMAIN | head -1
```
Ответ — `HTTP/2 200`. Значит, сертификат получен и сайт открыт.

## Шаг 8. Зарегистрироваться и подключить модель (15 минут)

1. Откройте в браузере `https://rakazo.ВАШ-IP.sslip.io`.
2. Зарегистрируйтесь **той самой почтой**, что в `SIGNUP_ALLOWLIST`. Вы — владелец. (Письма с подтверждением не будет: почтовая отправка не настроена, для первого аккаунта это нормально.)
3. Подключите модель: в настройках найдите подключение моделей (Models / Connect a model), выберите **OpenRouter** и вставьте ключ `sk-or-…` из шага 0. Модель для начала — любая из Claude, GPT или Gemini средней цены.

   Альтернатива: впишите ключ в файл и перезапустите —
   ```bash
   cd ~/rakazo
   sed -i "s|^OPENROUTER_API_KEY=.*|OPENROUTER_API_KEY=ВАШ_КЛЮЧ|" .env
   docker compose --env-file .env -f docker-compose.images.yml up -d
   ```

4. Первое задание боту, чтобы проверить его компьютер:
   ```
   Открой в браузере news.ycombinator.com и пришли мне 5 главных заголовков со ссылками.
   ```
   Откройте у бота **Agent computer** — увидите, как он сам открывает браузер.

✅ **Проверка:** бот прислал заголовки, а в окне Agent computer видно его рабочий стол.

## Шаг 10. Безопасность — 10 минут, не пропускайте

По умолчанию компьютер бота видит всю сеть сервера. Официальный «ограниченный режим» оставляет ему интернет, но закрывает доступ к самому серверу и служебным адресам провайдера:
```bash
cd ~/rakazo
curl -fsSLO https://raw.githubusercontent.com/elie222/rakazo/main/infra/compose/restrict-computer-egress.sh
sed -i "s|^# SANDBOX_COMPUTER_EGRESS=open|SANDBOX_COMPUTER_EGRESS=restricted|" .env
grep "^SANDBOX_COMPUTER_EGRESS" .env
bash restrict-computer-egress.sh
docker compose --env-file .env -f docker-compose.images.yml up -d supervisor
```

✅ **Проверка:** `grep` показал `SANDBOX_COMPUTER_EGRESS=restricted`, скрипт отработал без ошибок. Дайте боту ещё раз задание из шага 8 — интернет у него должен работать.

> Если скрипт ругается на `nftables` или iptables — пропустите этот шаг (верните строку: `sed -i "s|^SANDBOX_COMPUTER_EGRESS=restricted|# SANDBOX_COMPUTER_EGRESS=open|" .env` и снова `up -d supervisor`). Rakazo будет работать и без него; для своего тестового сервера это допустимо, для клиентского — разберитесь до сдачи.

Ещё три правила:
- Ключ OpenRouter — **только ваш** (у клиента — только его). Не пересылайте его в чатах.
- Файл `.env` никому не показывайте: в нём все пароли.
- Обновление Rakazo, когда понадобится:
  ```bash
  cd ~/rakazo
  docker compose --env-file .env -f docker-compose.images.yml pull
  docker compose --env-file .env -f docker-compose.images.yml up -d --wait
  ```
  Rakazo по умолчанию ставит самую свежую сборку (`edge`) — у клиентов перед обновлением делайте копию папки и базы.

## Шаг 11. Портфолио (30 минут)

Без примеров работ первый заказ на Kwork почти не приходит. Сделайте:

1. **Видео 60–90 секунд** (запись экрана): вы пишете боту задачу → открываете Agent computer → бот сам открывает сайт и находит ответ → тот же чат в телефоне. Без звука можно, подписи текстом.
   Задачи для показа, понятные заказчику:
   - «Найди 5 поставщиков <товара> в <городе> и сведи в таблицу: название, сайт, телефон»
   - «Каждое утро в 9:00 присылай мне сводку новостей по <теме>» (это «рутина» по расписанию)
2. **Три скриншота:** чат в браузере; рабочий стол агента; приложение в телефоне.
3. Загрузите видео на YouTube (доступ «по ссылке») или прямо в кворк.

✅ **Проверка:** есть ролик и 3 картинки, на которых не видно ваших ключей, почты и IP.

## Шаг 12. Гиг на Kwork (30 минут)

1. Зарегистрируйтесь на [kwork.ru](https://kwork.ru) как продавец и заполните профиль (фото, пара предложений о себе).

3. Заполните по шаблону ниже. Обложка — лучший скриншот с крупной подписью «Ваш ИИ-агент на вашем сервере». Kwork подскажет нужный размер картинки.

**Название:**
```
Установлю личного ИИ-агента на ваш сервер: OpenClaw или Rakazo, с мобильным приложением
```

**Описание:**

## Как работать с первым заказом

- Сервер клиент **арендует на свой аккаунт** и даёт вам временный доступ: попросите добавить ваш SSH-ключ (из шага 1). После сдачи попросите ключ удалить.
- Ключ ИИ-модели клиент заводит **сам** и вставляет сам — вы показываете куда.
- Шаги 3–10 этой инструкции = работа по заказу. Почта клиента идёт в `SIGNUP_ALLOWLIST`.
- Сдача: видео 30 секунд «агент на вашем сервере выполнил вашу задачу» + короткая памятка (адрес, как зайти с телефона, как обновить).

## Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| `ssh: connect to host … timed out` | Проверьте IP; у провайдера может быть свой брандмауэр в панели — откройте порты 22, 80, 443 |
| `docker: command not found` | Повторите шаг 3 |
| Установщик пишет `the Docker Compose plugin is required` | Повторите `curl -fsSL https://get.docker.com \| sh` |
| Установщик падает на `could not pull images` | Сеть до реестра образов; повторите `bash install-images.sh` — настройки сохранятся |
| `curl -sI https://…` не отвечает или ошибка сертификата | Проверьте `getent hosts $DOMAIN` (шаг 4) и `ufw status` (80 и 443 открыты). Логи: `journalctl -u caddy --no-pager -n 50` |
| В браузере `Blocked request. This host is not allowed` | Неверный `RAKAZO_HOST`. Проверьте `grep RAKAZO_HOST ~/rakazo/.env` (адрес без `https://`), затем `cd ~/rakazo && docker compose --env-file .env -f docker-compose.images.yml up -d` |
| Не даёт зарегистрироваться | Почта не совпадает с `SIGNUP_ALLOWLIST` (регистр, опечатка). Исправьте и `docker compose … up -d api` |
| Бот отвечает, но Agent computer не запускается | Не хватает памяти: `free -h`. Логи: `cd ~/rakazo && docker compose --env-file .env -f docker-compose.images.yml logs supervisor --tail 50`. Можно уменьшить память компьютера: добавить в `.env` строку `RAKAZO_COMPUTER_MEMORY=1536m` и `up -d supervisor` |
| Бот молчит | Не подключена модель или кончились деньги на OpenRouter — проверьте баланс на openrouter.ai |
| Что-то совсем сломалось | Логи всех сервисов: `docker compose --env-file .env -f docker-compose.images.yml logs --tail 100`. Скопируйте ошибку и спросите Claude — с логами он разберётся |
